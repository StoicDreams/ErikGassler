I take on contract and consulting work alongside my full-time role. If you have a project that needs a senior engineer who can own it from architecture to production, I'd like to hear about it. Availability depends on the project, so get in touch and we can talk it through.

What I can help with

Rust applications and libraries, GPU rendering with wgpu and WGSL, game engine systems, and desktop tools, drawing on my work building Fabric Engine and Task Proxy.

Finding and fixing what makes a system slow. At Microsoft I prototyped and partly built a re-architecture of a reporting service whose queries took from tens of seconds up to hundreds of minutes, bringing them down to between milliseconds and a few seconds.

New web applications or rebuilds of existing ones, in C# Blazor, React with TypeScript, or vanilla JavaScript with my Web UI framework, with Rust where heavy processing is needed.

Getting a team to ship small, tested changes to production every day: CI/CD pipelines, automated test suites, and the working practices from my book, CASE.

A second opinion on a system's design, codebase, or delivery process, with concrete, prioritized recommendations.

Workshops on unit testing and test-driven development, like the sessions I ran at Microsoft, and mentoring engineers as they grow into leads.

How I work with clients

  • Working software early. I deliver something usable as soon as possible, then improve it in small steps, so you see progress instead of status reports.
  • Tested and automated. Changes come with automated tests and deploy through a pipeline, so the project keeps working after I hand it over.
  • Clear ownership. I take responsibility for the work end to end, from architecture to deployment, and document what your team needs to carry it on.
